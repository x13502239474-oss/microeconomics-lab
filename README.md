# MICROECONOMICS LAB · 微观经济学研究所

移动端优先的微观经济学自学站：62 讲结构化讲义、7 个真实计算的交互实验室、8 个现实问题案例库、自动错题本。

**在线访问**：https://x13502239474-oss.github.io/microeconomics-lab/

---

## 课程体系

以曼昆《经济学原理·微观经济学分册》（第 10 版）的章序为骨架，自行撰写讲解，非教材原文摘录。

| 阶段 | 对应章节 | 讲数 |
| --- | --- | --- |
| 01 经济学基础 | 第 1–3 章 | 10 |
| 02 市场如何运行 | 第 4–5 章 | 11 |
| 03 市场与政府 | 第 6–9 章 | 10 |
| 04 消费者与生产者行为 | 第 14、22 章 | 10 |
| 05 不同市场结构 | 第 15–18 章 | 11 |
| 06 市场失灵与公共政策 | 第 10–11、23 章 | 10 |

每讲包含九个固定部分：学习目标、现实问题导入、核心概念、理论解释、数学公式及变量解释、图表与曲线分析、现实案例、本节总结、章节测试。

## 交互实验室

| # | 实验室 | 核心计算 |
| --- | --- | --- |
| 01 | 供需市场模拟器 | 线性供需联立求均衡 P、Q，消费者/生产者剩余 |
| 02 | 弹性计算器 | 中点公式需求价格弹性、收入变化方向 |
| 03 | 税收模拟器 | 从量税下的消费者价格、生产者净价、税收收入、无谓损失、归宿分担 |
| 04 | 企业成本实验室 | TC/AFC/AVC/ATC/MC 与 ATC 最低点 |
| 05 | 企业利润模拟器 | 给定需求与成本下的利润最大化产量、实际利润 |
| 06 | 市场结构模拟器 | 完全竞争 / 垄断 / 古诺寡头 / 垄断竞争的价格、产量、利润、福利损失 |
| 07 | 外部性模拟器 | 私人成本与社会成本、市场均衡 vs 社会最优、庇古税、福利改进 |

所有计算集中在 `src/lib/econ.ts`，讲义正文、静态图表、实验室滑杆和测验答案共用同一套公式，不会互相矛盾。

## 技术栈

React 18 · TypeScript（strict）· Vite 5 · Tailwind CSS 3 · KaTeX · Recharts · 自绘 SVG 图表引擎

数据全部存在浏览器 LocalStorage，无需登录；已预留云同步适配器接口（`src/lib/sync.ts`）。

## 本地开发

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建
npm run preview    # 预览构建产物

npm run verify     # 经济模型断言（33 项）
npm run qa         # 页面溢出 / 控制台报错巡检（需预览服务在 4380 端口）
npm run labels     # 全站图表文字重叠检测
```

## 部署

构建产物在 `dist/`，通过 `gh-pages` 分支发布：

```bash
npm run build
GH_TOKEN=<你的 token> node scripts/deploy.mjs pages
```

`base: './'` 配合 HashRouter，静态托管无需额外的路由回退配置。

## 内容说明

讲义为按知识体系自行撰写的版本，不包含教材原文段落，也不引用页码。案例中的数字为课堂算例或公开量级，不构成统计引用。未纳入主线的内容（第 12 章医疗经济学、第 13 章博弈论初步、第 19–21 章要素市场与收入分配）在站内 `/about` 页有说明。
